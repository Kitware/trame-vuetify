# Building

## Generating the Bundles

### Vuetify 3

1. Navigate to `v3-lab/`
2. Run `npm i` to install Vuetify v3
3. Run `npm run build` to generate the bundled JS, this should be present in `trame_vuetify/module/v3-lab-serve/trame-vuetify-lab.js`

### Vuetify 4

1. Navigate to `v4-lab/`
2. Run `npm i` to install Vuetify v4
3. Run `npm run build` to generate the bundled JS, this should be present in `trame_vuetify/module/v4-lab-serve/trame-vuetify-lab.js`

## Compiling the Python Bindings + Retrieving Fonts

Run `./build-bundles.sh`.
